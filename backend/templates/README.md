# 원본 양식 설치

이 폴더의 `26_순보고서.docx`가 공통 원본입니다. 파일명은 유니코드 정규화 후 확인합니다.
설정 화면에서 등록하면 해당 계정의 비공개 양식이 공용 파일보다 우선 적용됩니다.

현재 어댑터는 다음 표 구조를 인식합니다.

1. 공통 원본의 6열 표 두 개와 참석자별 나눔 셀
2. `이름`, `주일예배`, `대학부예배`, `순모임`, `큐티`, `설교나눔`, `삶나눔`, `기도제목` 열이 있는 표와 예시 데이터 행
3. `이름` 행 뒤에 `설교나눔`, `삶나눔`, `기도제목` 라벨과 값 셀이 반복되는 블록

모임 날짜/날짜/모임 일시 및 순장 라벨의 다음 셀을 채웁니다.
메타데이터에 `{{meetingDate}}`, `{{leader}}`, `{{title}}`, `{{meetingSummary}}` 토큰이 있으면 치환합니다.
원본 행의 XML을 복제해 행 높이·테두리·셀 병합·단락 및 첫 텍스트 run 스타일을 보존합니다.
공통 원본은 참가자 행의 고정 높이를 최소 높이로 바꾸고 행 분할을 허용합니다. 다른 양식은 긴 글과 페이지 나눔을 별도로 검증해야 합니다.
인식할 수 없는 구조는 오류로 안내하며 다른 문서를 원본이라고 생성하지 않습니다.
원본에 대한 회귀 테스트는 `backend/tests/test_original_docx.py`에서 실행합니다.
