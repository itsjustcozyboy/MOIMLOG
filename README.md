# 모임록 (MOIMLOG)

순모임 녹음을 검토하고 참석자별 나눔을 정리해 기존 `26_순보고서.docx`로 내려받는 웹앱입니다. 기존 사용자 계정, 수동 화자 연결, 로컬/AI 분석, 보고서 검토와 원본 DOCX 생성 기능을 유지합니다.

## 실행

Python 3.10+, Node.js 20+, npm이 필요합니다. 기존 음성파일 업로드 전사는 ffmpeg/ffprobe가 필요하고 직접 녹음은 AudioWorklet 지원 브라우저와 HTTPS(로컬호스트 예외)가 필요합니다.

```bash
bash scripts/setup.sh
npm run dev
```

프런트엔드 http://localhost:5173, API http://localhost:8000. `.env.example`을 참고해 `.env`를 설정하고 서버를 재시작합니다. Docker는 `docker compose up --build`로 실행합니다. **Uvicorn 단일 worker / 단일 서버 프로세스**로 운영해야 합니다. 복수 worker·복수 서버에 대한 분산 작업 잠금은 구현하지 않았습니다. SQLite 파일 세 개와 사용자 파일이 있는 DATA_DIR 전체를 영구 볼륨에 보관·백업하세요.

| 환경변수 | 용도 / 기본값 |
| --- | --- |
| `GROQ_API_KEY` | 실제 STT 키. 직접 녹음 화면에서 명시적으로 Mock을 선택하면 키 없이 체험 가능 |
| `GROQ_RPM`, `GROQ_RPD` | 조직 전체 분당/일일 호출 한도, 기본 20 / 2000 |
| `GROQ_ASH`, `GROQ_ASD` | 시간당/일일 음성 초 한도, 기본 7200 / 28800 |
| `AI_MONTHLY_BUDGET_KRW` | 전체 배포 Groq + OpenAI 월 예약액 상한, 기본 5000 |
| `USD_KRW` | 예산 계산용 환율, 기본 1500. 실시간 환율 아님 |
| `OPENAI_API_KEY`, `OPENAI_MODEL` | 선택적 AI 분류 키와 모델. 키가 없으면 수동 로컬 검토 |
| `OPENAI_INPUT_USD_PER_MILLION`, `OPENAI_OUTPUT_USD_PER_MILLION` | 확인한 모델 단가. 0/미설정이면 유료 분석 차단 |
| `DATA_DIR`, `DATABASE_URL` | 영구 데이터 경로와 선택적 앱 SQLite 주소 |
| `COOKIE_SECURE` | HTTPS 운영 시 true |

## 구현한 직접 녹음 흐름

참석자 입력 → 녹음·Groq 전송 동의 → 녹음 시작 → 약 15초마다 자동 STT → 종료·마지막 구간 처리 → 최종 전사문 확인 → 참석자별 수동 분류/선택적 AI 초안 → 순장 검토 → 기존 DOCX 다운로드. 별도 음성 업로드 승인은 필요하지 않습니다.

- `frontend/src/Recorder.tsx`, `public/pcm-worklet.js`: AudioWorklet에서 모노 PCM을 연속 수집하고 독립적인 WAV 헤더를 갖는 15초 구간을 생성합니다. MediaRecorder의 `ondataavailable` 조각을 독립 파일로 가정하지 않습니다. 기본 16kHz/16bit, 실제 AudioContext 샘플레이트를 WAV에 기록합니다.
- 매 구간을 IndexedDB에 먼저 저장한 뒤 순번을 붙여 서버로 보냅니다. 서버 미응답 시 기기 저장분을 재전송합니다. 원본 전체를 JS 배열에 누적하지 않으며, 서버 ACK 후에도 기기 복사본을 보관합니다. 녹음 종료 후 화면에서 기기 복사본을 삭제할 수 있습니다.
- 서버 `services/live.py`는 `recordings.sqlite`에 원본 BLOB과 순번·해시를 트랜잭션으로 저장합니다. 동일 요청 재전송은 무해하고, 동일 순번의 다른 데이터는 거절합니다. 빠진 선행 구간이 도착하기 전에는 후행 전사를 실행하지 않습니다. 원본은 STT 성공 여부와 독립적입니다.
- 별도 영속 큐 worker가 Groq의 공식 `POST /openai/v1/audio/transcriptions`를 호출합니다. 네이티브 스트리밍/WebSocket이 아닙니다. 큐가 비어 있을 때 지연은 대략 **15초 + API 응답 + 최대 2.5초 화면 폴링**입니다.
- 전사 시 이전 구간 끝 1초를 덧붙입니다. 구간 오프셋을 녹음 시간축으로 환산하고, 중첩 시간의 동일 어절을 제거하며 최대 약 8초 단위 발언으로 표시합니다. Groq 단어 타임스탬프를 우선 사용하고 세그먼트/전체 텍스트로 대체합니다. 시간축은 일시정지 시간을 제외한 녹음 시간입니다. 경계에서의 인식 오류·누락을 완전히 없애는 방식은 아니므로 최종 검토가 필요합니다.
- 확정 결과를 모임 전사문에 매 구간 저장합니다. 타이머, 음성 입력 크기, 연결 상태, 저장 대기 수, 구간별 처리/실패/예산 상태, 월 내부 예약액, 스크롤 전사 영역을 표시합니다. **화자 분리는 구현하지 않았으며 모든 자동 발언은 ‘화자 미확인’이고 참석자에게 임의 배정하지 않습니다.** 전사문 수정 후에도 이 표시는 미배정으로 유지됩니다.
- 일시정지는 현재 구간을 마감하고 재개 시 이어서 녹음합니다. 종료 시 마지막 짧은 구간도 처리합니다. 서버에 종료 구간 수를 보내 모든 순번과 전사가 완료된 후에만 검토로 이동합니다. 저장 중 수정/다른 분석으로 결과가 덮어써지지 않도록 API에서 차단합니다.
- STT 실패는 최대 3회까지 지수 지연 재시도하며 이후 수동 재시도할 수 있습니다. 429의 Retry-After도 반영합니다. 실패해도 녹음은 계속됩니다. 서버 재시작 시 processing 구간을 대기로 복구합니다. 응답 수신 전 서버 장애가 나면 중복 유료 호출 가능성이 있으며 재호출도 별도 예산으로 예약합니다.
- 새로고침 후 같은 모임의 ‘직접 녹음’ 탭에서 저장 구간을 복구하고 재개/종료할 수 있습니다. 종료 의도도 기기에 보관합니다. 서버 원본은 구간별 WAV로 다운로드할 수 있고 모임·계정 삭제 또는 보관 기간 만료 시 함께 삭제됩니다.

## 녹음 안정성과 보관 한계

120분 제한은 AudioWorklet의 샘플 수와 서버 누적 길이로 검사합니다. 16kHz PCM 원본은 2시간 약 **230MB**, 월 52시간 약 **6GB**입니다. 기기와 서버에 각각 공간이 필요하며 브라우저가 48kHz로 동작하면 약 3배입니다. 저장소 영구 보관 권한을 요청하지만 브라우저는 이를 거절하거나 데이터를 축출할 수 있습니다. 기기 저장 실패는 명확히 표시하고 캡처를 일시정지합니다.

네트워크 단절 전에 시작된 녹음은 기기에 계속 저장되고 복구 시 전송됩니다. **최초 서버 세션 생성에는 연결이 필요합니다.** 서버를 못 쓰는 동안 이미 서버에 수신된 원본도 유지됩니다. 새로고침·탭 강제 종료·OS 중단 직전 **아직 저장되지 않은 최대 15초**는 복구할 수 없습니다. 브라우저 녹음은 모바일 화면 잠금·전화·절전 중 계속 실행을 보장할 수 없으므로 화면을 켜 두세요. 마이크 종료와 AudioContext 중단은 복구 안내를 표시합니다. 실제 120분 연속 장치 녹음은 아직 미검증입니다.

## 비용과 동시 사용

2026-10-29 확인한 [Groq STT 공식 문서](https://console.groq.com/docs/speech-to-text)의 `whisper-large-v3-turbo` 가격 $0.04/시간, 호출당 최소 10초를 기준으로 합니다. 계획 환율은 1달러=1500원입니다.

| 월 52시간 가정 | 예상 STT 비용 |
| --- | ---: |
| 중첩·재시도 없는 기본값 | 3120원 |
| 15초마다 1초 중첩 (약 6.67% 증가) | 약 3328원 |
| 위 호출의 5%를 추가 재시도 | 약 3494원 |
| 26회의 마지막 짧은 구간을 각 최대 9초 추가 과금, 재시도 포함 | 추가 최대 약 4.10원 |
| 합계 예시 / 전체 5000원 중 잔여 | 약 3498원 / 약 1502원 |

정확한 산식은 `모든 시도에 대한 Σ max(10, 전송 음성 초) × 0.04 / 3600 × 설정 환율`입니다. 마지막 구간 수와 일시정지 횟수에 따라 최소 과금이 늘어납니다. 5% 재시도는 계획 가정이며 실제 장애가 많으면 더 비쌉니다. 분석은 잔여 예산에서만 허용하며 단가 미설정 시 로컬 검토를 사용합니다. OpenAI SDK 내부 자동 재시도는 꺼서 앱의 각 재시도마다 예약하도록 했습니다.

`usage.sqlite`의 UTC 월별 공용 예약 트랜잭션은 전체 API 예약 합계가 5000원을 넘는 신규 유료 요청을 차단합니다. 실패한 호출의 예약도 취소하지 않는 보수적 추정입니다. 녹음·원본 업로드는 계속되고 해당 전사 구간은 예산 대기로 남습니다. 다음 달 또는 예산 확인 후 수동 재시도할 수 있습니다. **내부 예약액은 공급자의 실제 청구액이 아닙니다.** 실제 환율·세금·공급자 청구 반올림·다른 앱의 동일 키 사용·실제 분석 토큰과 차이가 생깁니다. 앱 외 호출과 호스팅/저장 비용은 이 한도로 통제하지 않으므로 총 청구 5000원 보장은 아닙니다. 공급자 지출 제한과 청구서를 함께 확인해야 합니다.

6명 동시 녹음은 약 **24 RPM, 시간당 23040 음성 초**(1초 중첩 포함)를 요구합니다. [공식 기본 한도](https://console.groq.com/docs/rate-limits)의 무료 등급 20 RPM / 7200 ASH로는 준실시간 처리가 밀립니다. 기본값은 안전하게 대기시키며 원본 저장은 계속됩니다. [조직 Limits 화면](https://console.groq.com/settings/limits)의 실제 RPM/RPD/ASH/ASD를 확인해 환경변수에 반영하세요. 큐와 기존 파일 업로드는 같은 영속 한도 카운터를 사용합니다. 계정의 다른 서비스 사용량은 알 수 없으며 429에 따라 재시도합니다. 6명 동시 준실시간에는 충분한 조직 한도와 실측 API 처리속도가 필요합니다.

## 선택적 즉시 자막

SpeechRecognition 또는 webkitSpeechRecognition이 있는 브라우저에서만 별도 체크박스를 제공합니다. 기본 비활성이고 브라우저 제공업체로 음성이 전송될 수 있음을 표시한 뒤 사용자가 선택해야 시작합니다. 임시 자막은 서버에 저장하거나 보고서에 사용하지 않으며 최종 전사는 Groq 결과만 사용합니다. Mock과 함께 선택하더라도 브라우저 자막은 별도 외부 전송을 할 수 있습니다.

[MDN SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition)에 따르면 널리 지원되는 기능이 아니며 Chrome 등의 구현은 서버 기반으로 음성을 전송할 수 있습니다. 브라우저/OS에 따라 제공업체와 처리 정책이 다르고 한국어 온디바이스 인식은 보장하지 않습니다. MOIMLOG가 해당 업체의 보관·학습 정책을 통제하거나 검증한 것은 아닙니다. 민감한 모임은 이 선택 기능을 끄고 사용하세요. 실기기에서 자막과 AudioWorklet 동시 실행 호환성은 추가 검증 대상입니다.

## 양식과 실제 사용 가능한 기능

공통 `backend/templates/26_순보고서.docx`와 계정별 원본 업로드를 유지합니다. 8명 초과 시 원본 행을 복사하며, Word/LibreOffice의 실제 페이지 나눔은 별도 육안 검수가 필요합니다. 전사 없이 기존 TXT 업로드 → 화자 연결 → 로컬 검토 → DOCX도 계속 사용할 수 있습니다. Mock 녹음은 실제 음성 인식 없이 **[Mock 예시]** 문장을 생성하며 API 비용이 없습니다.

```bash
npm test
npm run build
npm run test:e2e
```

E2E는 실행 중인 개발 서버와 Playwright Chromium이 필요합니다. 테스트는 생성한 계정과 합성 음성을 사용합니다. 브라우저 테스트의 mobile은 Chromium iPhone 화면 크기 에뮬레이션이며 실제 Safari가 아닙니다.

## 테스트 결과 (2026-10-29)

- TypeScript/Vite 프로덕션 빌드 통과.
- 기존 프런트엔드 단위 테스트 3개 통과.
- 백엔드 회귀 및 신규 녹음 테스트: 최종 실행 결과 아래 갱신 예정.
- Playwright 6개 통과: 데스크톱/모바일 크기에서 기존 TXT 보고서 흐름, 실제 AudioWorklet + 가상 마이크 Mock 녹음, 누적 전사, 일시정지/재개, 통신 실패 중 로컬 보존과 재전송, 새로고침 복구, 미확인 발언 수동 분류, DOCX 다운로드.

- 실제 Groq/OpenAI 유료 요청, 한국어 인식 정확도와 실제 청구 금액은 **미검증**. 테스트에서 유료 API를 호출하지 않았습니다.
