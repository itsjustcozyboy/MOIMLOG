# 원본 양식 설치

교회에서 받은 실제 `26_순보고서.docx`를 이 폴더에 배치하세요.
원본이 제공되지 않아 이 저장소에는 DOCX를 포함하지 않았습니다.
설정 화면에서 등록하면 해당 계정의 비공개 양식이 공용 파일보다 우선 적용됩니다.

현재 어댑터는 다음 표 구조를 인식합니다.

1. `이름`, `주일예배`, `대학부예배`, `순모임`, `큐티`, `설교나눔`, `삶나눔`, `기도제목` 열이 있는 표와 예시 데이터 행
2. `이름` 행 뒤에 `설교나눔`, `삶나눔`, `기도제목` 라벨과 값 셀이 반복되는 블록

모임 날짜/날짜/모임 일시 및 순장 라벨의 다음 셀을 채웁니다.
메타데이터에 `{{meetingDate}}`, `{{leader}}`, `{{title}}`, `{{meetingSummary}}` 토큰이 있으면 치환합니다.
원본 행의 XML을 복제해 행 높이·테두리·셀 병합·단락 및 첫 텍스트 run 스타일을 보존합니다.
용량이 넘으면 행을 추가하며 Word의 자연 페이지 나눔을 사용합니다. 원본이 고정 높이/행 분할 금지이면 긴 글이 잘릴 수 있으므로 실제 원본으로 검증해야 합니다.
인식할 수 없는 구조는 오류로 안내하며 다른 문서를 원본이라고 생성하지 않습니다.
실제 원본을 받으면 `docx_generator.py` 어댑터 및 원본 기반 회귀 테스트를 추가해야 합니다.
